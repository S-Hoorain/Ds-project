# Data dictionary: master_model_ready.csv

1 row = 1 SPI week (ending Thursday) x 1 consumption group. 2,220 rows x 70 columns, 05 Sep 2019 to 01 Oct 2026. Generated by `notebooks/01_data_preparation.ipynb`.

| `group` | str | 0.0 | Consumption group: Q1 (poorest) ... Q5 (richest), or Combined (national) |
| `spi` | float64 | 0.0 | Sensitive Price Indicator, index (2015-16 = 100); revised value where PBS later revised it |
| `spi_prev_week` | float64 | 3.0 | Previous week's SPI as printed in this week's report (documentation column) |
| `spi_year_ago` | float64 | 0.0 | SPI in the corresponding week a year earlier (reported; else own value 52 weeks earlier) |

| `filled_from_next_report` | int64 | 0.0 | 1 if no report was published that week and SPI was taken from the next report |
